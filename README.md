Data analysis code associated with the paper: "Large cranial windows distort auditory cortical maps and degrade feature integration in secondary auditory cortex." Amber M. Kline, Hiroaki Tsukano, Muneshwar Mehra, Gates P. Schneider, Michellee M. Garcia, Hiroyuki K. Kato. iScience (2026)

Last updated: September 17, 2026, by Hiroyuki Kato

This repository provides sanitized MATLAB scripts illustrating the analyses underlying the figures in the manuscript. Mouse identifiers, directory names, and per-mouse parameters shown in the codes are placeholders/examples.
